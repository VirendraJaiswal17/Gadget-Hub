# Gadget-Hub
Developed a fully functional e-commerce platform with product listings, user authentication, and secure payment  integration to provide a seamless shopping experience.

Technologies Used: HTML5, CSS3, Bootstrap 5, JDBC, Servlets, MVC, JSP, Oracle.

Key Features: 
 User Authentication: Designed and implemented secure login and registration system.
 Product Listings: Developed dynamic, easily filterable product display with rich descriptions.
 Responsive UI: Created a mobile-first design using Bootstrap 5, ensuring cross-device compatibility.
 Database Management: Utilized Oracle and JDBC to efficiently manage and retrieve product and user data.
