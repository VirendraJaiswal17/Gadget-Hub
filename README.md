# Gadget-Hub

Gadget-Hub is a fully functional e-commerce platform that provides a seamless shopping experience with secure user authentication, dynamic product listings, and payment integration.

## 🚀 Features

- **User Authentication**: Secure login and registration system for users.
- **Product Listings**: Dynamic and filterable product display with detailed descriptions.
- **Responsive UI**: Mobile-first design using Bootstrap 5 for cross-device compatibility.
- **Database Management**: Efficient handling of user and product data using Oracle and JDBC.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, Bootstrap 5  
- **Backend**: Java (Servlets, JSP, MVC)  
- **Database**: Oracle (JDBC)
